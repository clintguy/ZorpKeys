# ZorpKeys

**ZorpKeys** is a minimalist, lightweight World of Warcraft addon for Mythic+ players who want a "no-nonsense" way to coordinate keys with their party. 

## Features
* **Minimalist Footprint:** Near-zero impact on game performance.
* **Party Sync:** Automatically requests keystone info from other ZorpKeys users in your party.
* **Clean Output:** Prints `<Character Name> - <Dungeon> <Level>` directly to party chat.
* **Anti-Spam:** Built-in 60-second internal cooldown.

## How to Use
Type `/zorpkeys` while in a party. This will share your key and request others to do the same.

## Installation
1. Download the latest release from CurseForge.
2. Extract into your `_retail_/Interface/AddOns` folder.
3. Restart WoW.
